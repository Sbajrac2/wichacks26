# Project README

## Cloning the Repo
git clone https://github.com/Sbajrac2/wichacks26.git

## Installing Dependencies
npm install

## Environment Setup
Create a .env.local file with:
- GEMINI_API_KEY
- ELEVENLABS_API_KEY
- OPENAI_API_KEY

## Running the App
npm run dev
